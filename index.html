Web Bluetooth on iPhone & iPad

Mobile Safari on iOS does not support the Web Bluetooth API natively.

Recommended Steps for iPhone:

  1. Install Bluefy – Web BLE Browser from the App Store.
  2. Paste this web dashboard's URL into Bluefy.
  3. Tap CONNECT BLE to pair with your ESP32-C6.

Android Chrome/Edge works out of the box with native Web Bluetooth.
